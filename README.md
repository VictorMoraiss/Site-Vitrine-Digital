# Site Vitrine Digital

Projeto de estudo da minha fase inicial em front-end: uma loja fictícia com foco em design e interação.

🔗 **Ver online:** https://victormoraiss.github.io/Site-Vitrine-Digital/

## O que tem
- Carrossel de produtos com setas e indicadores de slide
- Layout escuro com destaques em rosa e elementos animados
- Ajuste de rolagem lateral na página

## Tecnologias
HTML, CSS e JavaScript, sem frameworks.

## O que aprendi
- Estruturar uma página com HTML
- Montar um carrossel com JavaScript (clique e troca de slides)
- Usar CSS para layout, gradientes e efeitos

## O que eu faria diferente hoje
- Organizar o CSS em variáveis e partes reutilizáveis
- Cuidar de acessibilidade (alt nas imagens, contraste, teclado)
- Otimizar as imagens (WebP e tamanhos corretos)

## Onde estou hoje
Este projeto é do começo da minha jornada. Meu trabalho mais recente é o site da [D&G Decorações](https://www.dgdecoracoes.com.br), no ar com domínio próprio, e hoje estudo Lógica de Programação e JavaScript todos os dias.
